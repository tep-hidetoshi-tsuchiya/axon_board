# AXON実機結合テスト自動化

## 概要

AXON基板の金額・面番号変更シーケンスを半自動でテストするPythonスクリプトです。

## 特徴

- ✅ UART通信の自動化（CHKIRQ/ATIRQ/SETAXON/ACK）
- ✅ テストケース自動実行
- ✅ 結果レポート自動生成
- ⚠️ ボタン押下は手動操作（物理的な操作が必要）

## 必要な環境

### ハードウェア
- SOMA基板（ESP32-C6）または USB-UARTブリッジ
- AXON基板（実機）
- UART接続ケーブル

### ソフトウェア
- Python 3.7以上
- 必要なライブラリ:
  ```bash
  pip install pyserial colorama
  ```

## 使用方法

### 1. 基本的な実行

```bash
# Windowsの場合
python tools/test_axon_money_face_change.py --port COM3

# Linux/Macの場合
python tools/test_axon_money_face_change.py --port /dev/ttyUSB0
```

### 2. オプション指定

```bash
python tools/test_axon_money_face_change.py \
  --port COM3 \
  --baudrate 115200 \
  --timeout 2.0
```

### 3. テスト実行の流れ

1. スクリプトを起動
2. シリアルポート接続確認
3. テストケースごとに以下を繰り返し:
   - **【操作待ち】**表示 → ボタンを手動で押下
   - Enterキー押下 → 自動でUART通信実行
   - 結果判定
4. 全テスト完了後、サマリー表示

## カスタマイズ

### テストケース追加

`main()`関数内に新しいテストケースを追加:

```python
tester.run_test_case(
    tc_id='TC-XXXX',
    description='テスト項目名',
    face_before=0, cash_before=0,
    face_after=1, cash_after=1,
    button_operations='ボタン操作内容'
)
```

### タイムアウト調整

ボタン操作に時間がかかる場合、タイムアウトを延長:

```bash
python tools/test_axon_money_face_change.py --port COM3 --timeout 5.0
```

## トラブルシューティング

### ポート接続エラー

```
✗ シリアルポート接続失敗: [Errno 2] could not open port COM3
```

**対処法**:
- ポート名が正しいか確認
- 他のアプリケーションがポートを使用していないか確認
- デバイスマネージャーでポート番号を確認（Windows）

### ATIRQ受信タイムアウト

```
✗ ATIRQ受信タイムアウト
```

**対処法**:
- AXON基板の電源を確認
- UART配線を確認（TX-RX、RX-TXクロス接続）
- ボタン押下後にIRQ_N信号が出ているか確認

### CRCエラー

```
✗ ATIRQ CRCエラー (受信: 0x1234, 計算: 0x5678)
```

**対処法**:
- UART通信速度を確認（115200bps）
- ケーブルの品質を確認
- ノイズ対策を確認

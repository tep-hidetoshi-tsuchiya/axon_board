### 1.3 重要な設計変更

#### rotation_countの扱い

**Ver0.1実装 (誤り)**:
```
AXON → STATUS[15:8]=rotation_count → SOMA → TG
```

**Ver1.0仕様 (正しい)**:
```
AXON: STATUS[15:8]=ダイヤル回転数カウント, STATUS[7]=dial_rotate_flag
      (ダイヤル回転数は AXON内部でカウント・管理)

SOMA: prize_counter (FRAM管理, TGコマンドより)
      + ATIRQ STATUS[15:8] (AXON側カウント)
      → prize_counter → rotation_count (TG送信)
```

**重要な違い**:

| 項目 | Ver0.1 (誤り) | Ver1.0 (正しい) |
|-----|-------------|--------------|
| STATUS[15:8] | rotation_count として解釈 | ダイヤル回転数カウント（読込専用） |
| prize_counter管理 | SOMA側で自動カウント | TGコマンドより明示的に管理 |
| カウント同期 | AXONと自動同期 | SOMA側で同期確認・検証 |
| リセット | SETAXON Bit5で自動 | SETAXON Bit5＋FRAMクリア |

**結論**:
- AXONからダイヤル回転数を参考情報として受信（STATUS[15:8]）
- SOMA内部で`prize_counter`を管理（FRAM永続化）
- TGへは`prize_counter`を`rotation_count`として送信
- 検証時にAXON STATUS[15:8]と比較可能

```c
    if (detector == NULL) return false;

    // ✅ Ver1.0: Bit 7 (Latch式)
    bool dial_rotated = (status & S2A_STATUS_DIAL_ROTATE) != 0;

        return true;

    return false;
```

```c
/**
 * @file t2s_packet.c
 * @brief TG-SOMA プロトコル変換関数
 */

#include "t2s_packet.h"
#include "s2a_packet.h"

/**
 * @brief T2S SETAXON SET_FACE → S2A SETAXON SET_PRTS 変換
 */
uint8_t protocol_map_t2s_to_s2a_setaxon(uint8_t t2s_set_face) {
    uint8_t s2a_set_prts = 0x00;

    // Bit 7: AXON Reset → 別処理 (AXONRBT コマンド)
    // Bit 5: ダイヤル回転クリア
    if (t2s_set_face & T2S_SETAXON_FACE_DIAL_CLEAR) {
        s2a_set_prts |= S2A_SETAXON_PRTS_DIAL_CLEAR;
    }
    // Bit 4: 現金ブロックON
    if (t2s_set_face & T2S_SETAXON_FACE_CASH_BLOCK) {
        s2a_set_prts |= S2A_SETAXON_PRTS_CASH_BLOCK;
    }
    // Bit 3: 返却ボタンリセット
    if (t2s_set_face & T2S_SETAXON_FACE_BTN_RESET) {
        s2a_set_prts |= S2A_SETAXON_PRTS_COIN_RETURN_RST;
    }
    // Bit 2: 光センサーリセット
    if (t2s_set_face & T2S_SETAXON_FACE_SENSOR_RST) {
        s2a_set_prts |= S2A_SETAXON_PRTS_COIN_SENSOR_RST;
    }

    return s2a_set_prts;
}

/**
 * @brief S2A ATIRQ STATUS → T2S ATCKSB CHK_FACE 変換
 */
uint8_t protocol_map_s2a_to_t2s_atcksb(uint16_t s2a_status) {
    uint8_t t2s_chk_face = 0x00;

    // Bit 7-0: 1:1対応
    if (s2a_status & S2A_STATUS_DIAL_ROTATE)   t2s_chk_face |= T2S_ATCKSB_FACE_DIAL_ROTATE;
    if (s2a_status & S2A_STATUS_DOOR_OPEN)     t2s_chk_face |= T2S_ATCKSB_FACE_DOOR_OPEN;
    if (s2a_status & S2A_STATUS_CASH_BLOCK)    t2s_chk_face |= T2S_ATCKSB_FACE_CASH_BLOCK;
    if (s2a_status & S2A_STATUS_COIN_RETURN)   t2s_chk_face |= T2S_ATCKSB_FACE_BTN_PRESSED;
    if (s2a_status & S2A_STATUS_COIN_SENSOR)   t2s_chk_face |= T2S_ATCKSB_FACE_COIN_SENSOR;
    if (s2a_status & S2A_STATUS_CASHLESS_SOL)  t2s_chk_face |= T2S_ATCKSB_FACE_CASHLESS_SOL;
    if (s2a_status & S2A_STATUS_SOLDOUT)       t2s_chk_face |= T2S_ATCKSB_FACE_SOLDOUT;
    if (s2a_status & S2A_STATUS_FACE_VALID)    t2s_chk_face |= T2S_ATCKSB_FACE_VALID;

    return t2s_chk_face;
}
```

```c
// ========== ATIRQ STATUS bit definitions (STATUS[0:15]) ==========
// STATUS bit[15:8]: RFU ('0'固定) - Ver1.0仕様
// ★ 注意: rotation_countは使用しない

#define S2A_STATUS_FACE_VALID    (1 << 0)  // bit0: FACE有効無効
#define S2A_STATUS_SOLDOUT       (1 << 1)  // bit1: 売り切れ検知
#define S2A_STATUS_CASHLESS_SOL  (1 << 2)  // bit2: 電子マネー用ソレノイド [Latch式]
```

## 5. データフローとFRAM影響

### 5.1 rotation_count/prize_counter データフロー

```
【Ver0.1実装 - 誤り】
AXON → STATUS[15:8]=rotation_count → SOMA → TG (rotation_count)

【Ver1.0仕様 - 正しい】
AXON: STATUS[15:8]=RFU, STATUS[7]=dial_rotate
      ↓
SOMA: dial_rotate検知 → prize_counter++ (FRAM保存)
      ↓
TG:   rotation_count = prize_counter (FRAMから読出し)
```

### 5.2 FRAM影響評価

| 項目 | FRAM構造変更 | FRAM処理変更 | 結論 |
|-----|------------|------------|------|
| rotation_count削除 | ❌ 不要 | ❌ 不要 | ✅ 影響なし |
| STATUS[15:8]修正 | ❌ 不要 | ❌ 不要 | ✅ 影響なし |
| set_sol→set_prts | ❌ 不要 | ❌ 不要 | ✅ 影響なし |
| STATUS Bit 7追加 | ❌ 不要 | ✅ 必要* | ✅ 既存処理流用 |

*既存のprize_counter++処理を流用可能

### 5.3 FRAM操作まとめ

**変更不要**:
- FRAMメモリマップ（fram_axon_data_t構造体）
- FRAM読み書き処理（fram_memory_map.c）
- prize_counter管理（既に実装済み）

**変更必要**:
- ダイヤル回転検知トリガー: rotation_count差分 → dial_rotate Latch

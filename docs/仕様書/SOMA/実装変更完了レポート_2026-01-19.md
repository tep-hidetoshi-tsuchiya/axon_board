## 3. 変更詳細

### 3.1 SETAXON SET_PRTS ビット定義 (Ver1.0)

**s2a_packet.h (Line 88-101):**

```c
// ============================================================
// SETAXON - AXON board setting command (HD:0x14, ID:0x4A)
// ============================================================
// SET_PRTS bit definitions (Ver1.0)
#define S2A_SETAXON_PRTS_DIAL_CLEAR      (1 << 5)  // bit5: ダイヤル回転クリア
#define S2A_SETAXON_PRTS_CASH_BLOCK      (1 << 4)  // bit4: 現金ブロック
#define S2A_SETAXON_PRTS_COIN_RETURN_RST (1 << 3)  // bit3: 返却ボタンリセット
#define S2A_SETAXON_PRTS_COIN_SENSOR_RST (1 << 2)  // bit2: 光センサーリセット
```

**変更前 (Ver0.1):**
- bit0: ソレノイドON (削除)
- bit4: 現金ブロックON (継続)

**変更後 (Ver1.0):**
- bit2: 光センサーリセット (新規)
- bit3: 返却ボタンリセット (新規)
- bit4: 現金ブロックON (継続)
- bit5: ダイヤル回転クリア (新規)

### 3.3 STATUS bit7 追加 (ダイヤル回転検知 Latch式)

**axon_status.h (Line 1-27):**

```c
// ATIRQ STATUS bit definitions (Table 4-16準拠、16ビット)
// Ver1.0 仕様対応:
// bit[15:8]: ダイヤル回転数カウント（0x00→0xFF循環、SETAXON bit5でリセット）
// bit7: ダイヤル回転検知 [Latch式] (1=回転検知、SETAXON bit5でクリア)
// bit6: ドア開閉 (1=開)
// bit5: 現金ブロック (1=ON)
// bit4: 返却ボタン [Latch式] (1=押下、SETAXON bit3でクリア)
// bit3: 光センサー [Latch式] (1=検知、SETAXON bit2でクリア)
// bit2: 電子マネーソレノイド (1=ON)
// bit1: 売り切れ (1=売り切れ)
// bit0: FACE有効フラグ (1=有効)

#define STATUS_DIAL_ROTATE_BIT   (1U << 7)  // ダイヤル回転検知 [Latch式] (Ver1.0)
```

**axon_status.h (Line 95-107):**

```c
// bit6: ドア開閉
if (s->door_open) {
    status |= STATUS_DOOR_OPEN_BIT;
}

// bit7: ダイヤル回転検知 [Latch式] (Ver1.0)
if (s->dial_rotated) {
    status |= STATUS_DIAL_ROTATE_BIT;
}

// bit[15:8]: ダイヤル回転数カウント（新仕様 Table 4-16準拠）
status |= ((uint16_t)s->dial_rotation_count) << 8;
```

### 3.4 Latchクリア機能実装

**s2a_packet.c (Line 863-888):**

```c
// 7. 設定処理 (Ver1.0)
// SET_PRTS (bit5: Dial Clear, bit4: Cash Block, bit3: Btn Reset, bit2: Sensor Reset)
uint8_t set_prts = setaxon->set_prts;

// bit5: ダイヤル回転検知（Latch）クリア
if (set_prts & S2A_SETAXON_PRTS_DIAL_CLEAR) {
    extern volatile uint8_t g_dial_rotation_count;
    g_dial_rotation_count = 0;  // カウンタリセット
    g_axon_status_shared.dial_rotated = 0;  // Latchクリア
}

// bit4: 現金ブロックソレノイド制御
if (set_prts & S2A_SETAXON_PRTS_CASH_BLOCK) {
    DL_GPIO_writePinsVal(BLOCK_SOL_PORT, BLOCK_SOL_PIN, BLOCK_SOL_PIN);
} else {
    DL_GPIO_writePinsVal(BLOCK_SOL_PORT, BLOCK_SOL_PIN, 0);
}

// bit3: 現金返却ボタン（Latch）リセット
if (set_prts & S2A_SETAXON_PRTS_COIN_RETURN_RST) {
    g_axon_status_shared.escrow_detected = 0;
}

// bit2: 現金用 光センサー（Latch）リセット
if (set_prts & S2A_SETAXON_PRTS_COIN_SENSOR_RST) {
    g_axon_status_shared.coin_detected = 0;
}
```

**機能説明:**

| Bit | 機能 | 実装内容 |
|-----|------|---------|
| bit5 | ダイヤル回転クリア | `g_dial_rotation_count = 0`<br>`g_axon_status_shared.dial_rotated = 0` |
| bit4 | 現金ブロック制御 | GPIO制御 (ON/OFF切替) |
| bit3 | 返却ボタンリセット | `g_axon_status_shared.escrow_detected = 0` |
| bit2 | 光センサーリセット | `g_axon_status_shared.coin_detected = 0` |

## 4. 互換性への影響

### 4.1 Ver0.1 との非互換性

| 項目 | Ver0.1 | Ver1.0 | 影響 |
|-----|--------|--------|------|
| SETAXON bit0 | ソレノイドON | RFU (未使用) | ⚠️ 機能削除 |
| SETAXON bit2 | RFU | 光センサーリセット | ✅ 新機能 |
| SETAXON bit3 | RFU | 返却ボタンリセット | ✅ 新機能 |
| SETAXON bit5 | RFU | ダイヤル回転クリア | ✅ 新機能 |
| STATUS bit7 | RFU | ダイヤル回転検知 | ✅ 新機能 |

**互換性対応:**
- Ver0.1デバイスは Ver1.0 コマンドの新ビット (2,3,5,7) を無視する
- Ver1.0デバイスは Ver0.1 コマンドの bit0 を無視する (RFU扱い)

### 4.2 テスト推奨項目

1. **Latchクリア動作**:
   - SETAXON bit5 送信 → STATUS bit7 = 0 確認
   - SETAXON bit3 送信 → STATUS bit4 = 0 確認
   - SETAXON bit2 送信 → STATUS bit3 = 0 確認

2. **ダイヤル回転数カウント**:
   - ダイヤル回転 → STATUS[15:8] インクリメント確認
   - SETAXON bit5 送信 → STATUS[15:8] = 0 確認
   - 0xFF → 0x00 ラップアラウンド確認

3. **現金ブロック制御**:
   - SETAXON bit4 = 1 → GPIO ON 確認
   - SETAXON bit4 = 0 → GPIO OFF 確認

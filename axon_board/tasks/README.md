# TG–SOMA タスク一覧（7 シーケンス準拠）

## 概要
このディレクトリには、SOMA基板のTG（Terminal Gateway）連携機能に関するタスク定義が含まれています。各タスクは仕様書「7. シーケンス」に準拠した実装項目です。

## タスク構成

### 基本動作
- **7.1** [SOMA基板PORT確認](./7.1_SOMA_PORT_Check.md)
  - AXONポート自動スキャン
  - STATUS送信開始
  - 20ms周期Polling

### 設定・変更
- **7.2** [AXON設定Table伝搬](./7.2_AXON_Config_Propagation.md)
  - TG→SOMA設定受信
  - AES復号・CRC検証
  - SOMA→AXON転送

- **7.3** [金額・面番号変更の事前準備](./7.3_Change_Preparation.md)
  - 変更要求受信
  - FRAM差分検出
  - ボタン監視

- **7.4** [面番号変更（保存データ有）](./7.4_Face_Change_with_Data.md)
  - FACE重複チェック
  - 設定変更適用

- **7.5** [面番号変更（0面利用）](./7.5_Face_Change_Zero.md)
  - 0面初期化処理
  - 無効化フラグ設定

### 動作制御
- **7.6** [ダイヤル回転サブルーチン](./7.6_Dial_Rotation.md)
  - 回転検出
  - カウンタ更新
  - STATUS通知

- **7.7** [通常動作（購入）](./7.7_Normal_Purchase.md)
  - 現金購入処理
  - キャッシュレス購入処理
  - ソレノイド制御

- **7.8** [通常動作（購入以外）](./7.8_Normal_Non_Purchase.md)
  - 現金返金処理
  - キャッシュレス中止
  - 処理未了対応

- **7.9** [運用動作](./7.9_Operation_Mode.md)
  - モード切り替え
  - 0円設定
  - メンテナンス機能

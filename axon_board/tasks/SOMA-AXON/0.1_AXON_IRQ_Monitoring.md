# 0.1 AXON IRQ監視システム（ESP32-C6版）

## 概要
ESP32-C6ベースのSOMA基板において、IOExpander経由でAXON基板からのIRQ信号を監視するシステム。PORT 1-8はIOExpander Port0、PORT 9はIOExpander Port1 P1_0で監視する。

### AXON IRQ処理シーケンス

```
[AXON] IRQ信号 Low → SOMAに通知
   ↓
[SOMA] CHKIRQコマンド送信 (0x49)
   ↓
[AXON] ATIRQ応答送信 (0x6A)
   ↓
[AXON] IRQ信号 High ← ここでクリア
   ↓
[SOMA] SETAXONコマンド送信 (0x4A) または ACK (0x00)
   ↓
[AXON] ACK応答送信 (0x00)
   ↓
[AXON] IRQ信号 High ← 念のため再クリア
```

#### IRQ信号仕様
- **Active-Low**: Low (0V) = IRQ発生、High (3.3V) = 通常状態
- **クリアタイミング**: ATIRQ応答送信後、ACK応答送信後（2回）
- **プルアップ**: なし（ハードウェア制約、未接続時はフローティング）

## ESP32-C6とTI MSPM0の差異

### 元仕様（TI MSPM0）
```
AXON IRQ信号 → SOMA GPIO（PA0,PA1,PA9,PA15,PA16,PA27-PA30）
                  ↓
              GPIO割り込み
                  ↓
              フラグ設定
```

### ESP32-C6実装
```
AXON IRQ信号（PORT 1-8） → IOExpander Port1（P1_0-P1_7）
                              ↓
                         IOExpander INT信号
                              ↓
                         ESP32 GPIO9（未実装）
                              ↓
                      現在：50msポーリング
                      将来：GPIO割り込み
```

## ハードウェア接続

### IOExpander (PI4IOE5V6416ZDEX)

| IOExpander Pin | 信号名 | 接続先 | 方向 | プルアップ |
|---------------|--------|--------|------|-----------|
| P0_0 | AXON_IRQ_1 | AXON PORT_1 IRQ | 入力 | なし ⚠️ |
| P0_1 | AXON_IRQ_2 | AXON PORT_2 IRQ | 入力 | なし ⚠️ |
| P0_2 | AXON_IRQ_3 | AXON PORT_3 IRQ | 入力 | なし ⚠️ |
| P0_3 | AXON_IRQ_4 | AXON PORT_4 IRQ | 入力 | なし ⚠️ |
| P0_4 | AXON_IRQ_5 | AXON PORT_5 IRQ | 入力 | なし ⚠️ |
| P0_5 | AXON_IRQ_6 | AXON PORT_6 IRQ | 入力 | なし ⚠️ |
| P0_6 | AXON_IRQ_7 | AXON PORT_7 IRQ | 入力 | なし ⚠️ |
| P0_7 | AXON_IRQ_8 | AXON PORT_8 IRQ | 入力 | なし ⚠️ |
| P1_0 | AXON_IRQ_9 | AXON PORT_9 IRQ | 入力 | なし ⚠️ |
| INT | - | ESP32 GPIO9 | 出力 | 10kΩ (R97) |

**注意**: IRQ信号にプルアップ抵抗がないため、未接続ポートはフローティング状態になります。

### ESP32-C6 GPIO

| GPIO | 信号名 | 用途 | プルアップ |
|------|--------|------|-----------|
| GPIO9 | IOExpander INT | IOExpander割り込み入力 | 10kΩ (R97) |

## 性能特性

### 現在（ポーリング方式）
- **応答遅延**: 最大50ms（平均25ms）
- **CPU負荷**: 50ms周期でI2C通信
- **リアルタイム性**: 低
- **実装難易度**: 低
- **安定性**: 高

### 将来（割り込み方式）
- **応答遅延**: <1ms
- **CPU負荷**: IRQ発生時のみ
- **リアルタイム性**: 高
- **実装難易度**: 中
- **安定性**: 中（ISR設計が重要）

## エラーハンドリング

| エラー | 検出 | 対処 |
|-------|------|------|
| IOExpander通信失敗 | I2Cタイムアウト | 次回ポーリングでリトライ |
| UART受信タイムアウト | 100ms経過 | ログ出力、統計記録 |
| 複数IRQ同時検出 | ビットカウント | 順次処理（PORT 1→8） |
| MUX切替失敗 | GPIO制御エラー | エラーログ |
| 不明なコマンドID | ID判定 | 警告ログ |

### Step 1: GPIO9割り込み実装
```c
// GPIO9を立ち下がりエッジ割り込みで設定
gpio_set_intr_type(GPIO_NUM_9, GPIO_INTR_NEGEDGE);

```

### Step 2: ISR + タスク分離
```c
static void IRAM_ATTR axon_irq_isr_handler(void* arg) {
    BaseType_t xHigherPriorityTaskWoken = pdFALSE;
    // タスク通知
    vTaskNotifyGiveFromISR(axon_irq_task_handle, 
                           &xHigherPriorityTaskWoken);
    portYIELD_FROM_ISR(xHigherPriorityTaskWoken);
}
```

### Step 3: ポーリングと割り込みの併用
- 割り込み: 優先的に処理（低遅延）
- ポーリング: 補完的にスキャン（取りこぼし防止）

# 7.6 ダイヤル回転サブルーチン

## 概要
AXON側のダイヤル回転検出（ROT_DET）とブロック状態（BLK_ON）を定期的にCHKIRQで取得。回転検知により売上成立と判定し、FRAMカウンタを+1する。

## 使用コマンド

### SOMA → AXON
- **CHKIRQ (0x49)**: 周期的な状態確認要求

### AXON → SOMA
- **ATIRQ (0x6A)**: 状態応答
  - status: 状態ビットフィールド
    - ROT_DET: 回転検出ビット
    - BLK_ON: ブロック状態ビット
    - COIN_DET: 硬貨検出ビット

  ```c
      FRAM_AXON_Entry entry;
      fram_load_entry(port, &entry);
      entry.counter++;
      if (entry.counter == 0) {
          // オーバーフロー検出（32bit max到達）
          entry.counter = 0;
      }
      fram_update_entry(port, &entry);
      return ESP_OK;
  }
  ```

## ビットフィールド定義

```c
// status ビットフィールド (例)
#define ROT_DET_BIT   (1 << 0)  // bit0: 回転検出
#define BLK_ON_BIT    (1 << 1)  // bit1: ブロック中
#define COIN_DET_BIT  (1 << 2)  // bit2: 硬貨検出
#define ESCRW_DET_BIT (1 << 3)  // bit3: 返金検出
// ... その他の状態ビット
```

## エラーケース

| 状況 | 検出 | 対処 |
|-----|------|------|
| 回転未検出 | タイムアウト（例: 10秒） | カウンタ増加なし、TGへ通知 |
| 連続回転 | ROT_DET連続検出 | 1回のみカウント |
| 通信エラー | ATIRQ受信失敗 | リトライ、エラーログ |
| FRAMエラー | カウンタ更新失敗 | エラー記録、TGへ通知 |

## 備考
- 50ms周期で全ポートを監視
- 1回転 = 1個販売 = カウンタ+1
- 複数ポート同時回転検出時は順次処理
- カウンタは32bit（最大 4,294,967,295 個）
- オーバーフロー時は0に戻る
- 回転検出からTG通知までの遅延: 最大100ms

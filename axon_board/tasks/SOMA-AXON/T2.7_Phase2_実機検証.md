## 📊 検証シーケンス

### Phase 2.1: FRAMカウンタAPI検証
```
SOMA → AXON: SETAXON (FRAM_INCREMENT_TEST)
AXON → AXON: fram_increment_counter() 実行
AXON → AXON: カウンタ値確認、オーバーフロー防止確認
AXON → SOMA: ACK (結果データ付き)
```

### Phase 2.2: ダイヤル回転検出検証
```
SOMA → AXON: CHKIRQ
AXON → SOMA: ATIRQ (ROT_DET, BLK_ON含むSTATUS)
SOMA → AXON: SETAXON (ROTATION_MONITOR_MODE)
AXON → AXON: 状態機械遷移監視開始
[ユーザー: ダイヤル回転操作]
AXON → AXON: Idle→Pulse_1→Interval→Pulse_2→Complete
AXON → SOMA: 自動ATIRQ送信（回転検出通知）
```

### Phase 2.3: 購入処理検証
```
SOMA → AXON: SETAXON (PURCHASE_TEST_MODE)
SOMA → [現金投入シミュレート]
SOMA → AXON: CHKIRQ
AXON → SOMA: ATIRQ (COIN_DET=1)
[ユーザー: ダイヤル回転]
AXON → SOMA: 自動ATIRQ (ROT_DET=1)
AXON → AXON: fram_increment_counter() 実行
SOMA → 購入完了確認
```

### Phase 2.4: 非購入処理検証
```
SOMA → AXON: SETAXON (NON_PURCHASE_TEST_MODE)
SOMA → [エスクロSW押下シミュレート]
SOMA → AXON: CHKIRQ
AXON → SOMA: ATIRQ (ESCRW_DET=1)
AXON → AXON: 返金処理記録
SOMA → 返金完了確認
```

### Phase 2.5: 面番号変更検証
```
SOMA → AXON: SETAXON (FACE_CHANGE_TEST_MODE)
SOMA → [ボタン長押しシミュレート]
AXON → AXON: 面番号変更モード突入
AXON → AXON: 重複チェック実行
AXON → AXON: FRAMデータ継承確認
SOMA → AXON: CHKIRQ
AXON → SOMA: ATIRQ (新面番号データ)
```

### Phase 2.6: 運用動作検証
```
SOMA → AXON: SETAXON (OPERATION_TEST_MODE)
SOMA → [ドア開閉シミュレート]
SOMA → AXON: CHKIRQ
AXON → SOMA: ATIRQ (DOOR_OPEN=1)
SOMA → [磁気センサーシミュレート]
SOMA → AXON: CHKIRQ
AXON → SOMA: ATIRQ (SOLD_OUT=1)
```

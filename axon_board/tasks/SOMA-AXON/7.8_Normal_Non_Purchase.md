# 7.8 通常動作（購入以外）

## 概要
購入以外の動作として、現金返金・キャッシュレス中止・キャッシュレス処理未了の3つのシーケンスを処理。いずれもカウンタは増加させない。

## 使用コマンド

### SOMA → AXON
- **CHKIRQ (0x49)**: 状態確認
- **SETAXON (0x4A)**: ソレノイドOFF制御

### AXON → SOMA
- **ATIRQ (0x6A)**: 状態応答
  - ESCRW_DET: 返金検出
  - ROT_DET: 回転検出
  - BLK_ON: ブロック状態

---

## A. 現金返金シーケンス

### 概要
顧客が返金ボタンを押下、またはタイムアウトにより硬貨が返却される。AXON側で自律処理され、SOMA側は状態監視のみ実施。

### タスク詳細

#### 1. 返金検出 ✅
- [x] ESCRW_DET を ATIRQ で確認
- [x] 定期CHKIRQ送信（50ms周期）
- [x] ATIRQ応答の status 解析
- [x] ESCRW_DETビット確認
  ```c
  bool escrw_det = (status & ESCRW_DET_BIT) != 0;
  ```

#### 2. 返金状態監視 ✅
- [x] 返金処理の完了確認
- [x] BLK_ON状態の確認
  ```
  1. ESCRW_DET=1 (返金開始)
  2. BLK_ON=1 (返金処理中)
  3. BLK_ON=0 (返金完了)
  ```

#### 3. カウンタ非増加
- [ ] カウンタは増加させない
- [ ] 返金はノーカウント
- [ ] 売上統計から除外

#### 4. TG通知
- [ ] 返金完了STATUSをTGに送信
- [ ] 返金金額
- [ ] 返金理由（オプション）

## B. キャッシュレス中止シーケンス

### 概要
決済処理中にユーザーがキャンセル、またはTGからの中止要求により処理を中断。ソレノイドがON状態の場合は強制OFFする。

### タスク詳細

#### 1. TG中止要求受信
- [ ] 状態確認
- [ ] TGから中止コマンド受信
- [ ] 中止理由の確認
  - ユーザーキャンセル
  - 決済エラー
  - タイムアウト
  - システムエラー

#### 2. 現在状態の確認 ✅
- [x] CHKIRQで現在状態を取得
- [x] ソレノイド状態の確認
- [x] 回転検出の有無確認
  ```c
  if (rot_det) {
      // 既に回転済み→中止不可
      return ERROR_ALREADY_SOLD;
  }
  ```

#### 3. ソレノイドOFF制御 ✅
- [x] ソレノイド OFF を SOMA–AXON に送信
- [x] SETAXON構築（強制OFF）
  ```c
  SETAXON_PACKET setaxon;
  setaxon.command = 0x4A;
  setaxon.face_n = target_face;
  setaxon.set_sol = 0x00;  // ソレノイド強制OFF
  setaxon.set_led = 0x00;
  setaxon.set_tout = timeout_value;
  // CRC16計算
  ```
- [x] UART送信
- [x] ACK確認

#### 4. カウンタ非増加
- [ ] カウンタは増加させない
- [ ] 中止処理はノーカウント

#### 5. TG STATUS送信
- [ ] TG に STATUS 送信
- [ ] 中止完了通知
- [ ] 中止理由コード
- [ ] 決済IDの記録（オプション）

## エラーコード定義

```c
typedef enum {
    ERROR_NONE = 0x00,
    ERROR_CANCEL_USER = 0x01,      // ユーザーキャンセル
    ERROR_CANCEL_PAYMENT = 0x02,   // 決済エラー
    ERROR_ROTATION_TIMEOUT = 0x03, // 回転タイムアウト
    ERROR_SOL_CONTROL = 0x04,      // ソレノイド制御失敗
    ERROR_ALREADY_SOLD = 0x05,     // 既に販売済み（中止不可）
} Error_Code;
```

## 備考
- いずれのケースもカウンタ増加なし
- 返金: AXON自律処理
- 中止: TG指示による強制停止
- 未了: タイムアウトによる自動処理
- エラーログは必須（トラブルシュート用）
- タイムアウト時間は設定可能（デフォルト: 10秒）

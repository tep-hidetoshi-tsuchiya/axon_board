# 7.9 運用動作

## 概要
メンテナンスモード・テストモード等の運用動作を処理。0円設定・売り切れ状態の管理を行い、FRAM値を参照して適切な動作を決定する。

## 使用コマンド

### SOMA → AXON
- **CHKIRQ (0x49)**: 状態確認・ドア開閉検出
- **SETAXON (0x4A)**: 0円設定・LED制御

### AXON → SOMA
- **ATIRQ (0x6A)**: 状態応答
  - status: 運用状態ビット
    - DOOR_OPEN: ドア開放状態
    - SOLD_OUT: 売り切れ状態
    - ERROR_STATE: エラー状態

---

## A. 0円設定シーケンス

### 概要
メンテナンスモードや特別イベント時に金額を0円に設定。ドア開閉状態を監視し、適切なタイミングで設定変更を実施。

### タスク詳細

#### 1. 内部状態取得
- [ ] 内部状態を取得（ドアOPEN/CLOSE 等）
- [ ] 定期CHKIRQ送信
- [ ] ATIRQ応答の status 解析
- [ ] ドア開閉状態の取得
  ```c
  bool door_open = (status & DOOR_OPEN_BIT) != 0;
  ```

#### 2. FRAM参照と動作決定
- [ ] FRAM 値を参照し動作決定
- [ ] fram_load_entry(port, &entry) 呼び出し
- [ ] 現在の運用モード確認
- [ ] 0円設定の妥当性判定
  ```c
  if (door_open) {
      // ドア開放中は設定変更可能
      allow_change = true;
  }
  ```

#### 3. 0円設定の実施 ✅
- [x] SETAXON送信（金額=0円）
  ```c
  SETAXON_PACKET setaxon;
  setaxon.command = 0x4A;
  setaxon.face_n = entry.face_num;
  setaxon.set_sol = 0x00;
  setaxon.set_led = 0x00;
  setaxon.set_tout = entry.timeout;
  setaxon.set_face_n = entry.face_num;
  setaxon.set_cash_vlu = 0x0000;  // 0円
  // CRC16計算
  ```
- [ ] UART送信
- [ ] ACK確認

#### 4. FRAM更新
- [ ] FRAMに0円設定を保存
  ```c
  entry.cash_value = 0x0000;
  fram_update_entry(port, &entry);
  ```

#### 5. TG通知
- [ ] TGへ0円設定完了通知
- [ ] 設定変更STATUSの送信

### 0円設定の用途

| 用途 | 説明 | 期間 |
|-----|------|------|
| 無料配布イベント | プロモーション時の無料提供 | 数時間〜数日 |
| メンテナンス | 動作確認・テスト時 | 数分〜数時間 |
| 新商品お試し | サンプル配布 | 数日〜数週間 |
| キャンペーン | 条件付き無料提供 | 指定期間 |

## B. 売り切れ（LED色変更なし）シーケンス

### 概要
FACE売り切れ状態をAXONから取得し、キャッシュレスブロックの判断に使用。FRAM設定を参照して在庫管理を実施。

### タスク詳細

#### 1. 売り切れ状態取得
- [ ] FACE 売り切れ状態を AXON から取得
- [ ] 定期CHKIRQ送信
- [ ] ATIRQ応答の status 解析
- [ ] SOLD_OUTビット確認
  ```c
  bool sold_out = (status & SOLD_OUT_BIT) != 0;
  ```

#### 2. キャッシュレスブロック判断
- [ ] キャッシュレスブロックの判断に使用
- [ ] 売り切れ時の動作
  ```c
  if (sold_out) {
      // キャッシュレス購入を拒否
      cashless_blocked = true;
      // 現金購入は継続（AXON側で制御）
      cash_allowed = true;
  }
  ```

#### 3. FRAM設定参照
- [ ] FRAM の FACE 設定を参照
- [ ] fram_load_entry(port, &entry) 呼び出し
- [ ] 在庫数の確認（オプション）
  ```c
  if (entry.stock_count == 0) {
      // 在庫切れ
      sold_out = true;
  }
  ```

#### 4. TGへ売り切れ通知
- [ ] TGへ売り切れSTATUS送信
- [ ] 対象FACE番号
- [ ] 残在庫数（0個）
- [ ] 最終販売時刻

#### 5. 在庫補充検出
- [ ] ドア開閉によるリセット
- [ ] 在庫補充後の状態更新
  ```c
  if (door_open && prev_sold_out) {
      // 在庫補充の可能性
      sold_out = false;
      // 再度AXON状態確認
  }
  ```

## 状態ビットフィールド定義

```c
// status ビットフィールド (運用動作用)
#define DOOR_OPEN_BIT   (1 << 4)  // bit4: ドア開放
#define SOLD_OUT_BIT    (1 << 5)  // bit5: 売り切れ
#define ERROR_STATE_BIT (1 << 6)  // bit6: エラー状態
#define MAINT_MODE_BIT  (1 << 7)  // bit7: メンテナンスモード
```

## 備考
- 0円設定は運用上の特殊モード
- 売り切れ状態でも現金購入は可能（AXON判断）
- キャッシュレスは売り切れ時に即座にブロック
- ドア開放中は設定変更可能
- メンテナンスモードは管理者権限必要
- LED色変更なし（仕様）→将来的に実装可能

# 7.3 金額 or 面番号変更の事前準備

## 概要
金額または面番号変更前の事前準備として、AXONボードのボタン押下・長押し状態を取得。現在のFRAM設定を参照して変更処理の準備を行う。

## 使用コマンド

### SOMA → AXON
- **CHKIRQ (0x49)**: 状態確認要求

### AXON → SOMA
- **ATIRQ (0x6A)**: 状態応答（ボタン押下状態含む）
  - status: 状態ビットフィールド
    - bit0: ボタン押下
    - bit1: ボタン長押し
    - その他: 運用状態

## 状態遷移図

```
[待機状態]
    ↓
  ボタン検出？
    ↓YES
┌──────────────┐
│ CHKIRQ送信   │
│ (状態確認)   │
└──────┬───────┘
       ↓
┌──────────────┐
│ ATIRQ解析    │
│ (status取得) │
└──────┬───────┘
       ↓
  長押し？
   ↓YES       NO(短押し)
[面番号変更]  [金額変更]
   ↓            ↓
[FRAM参照]   [FRAM参照]
   ↓            ↓
[準備完了]   [準備完了]
```

## ボタン押下パターン

| パターン | 検出条件 | 動作 |
|---------|---------|------|
| 短押し | 0.1秒以上1秒未満 | 金額変更モード |
| 長押し | 3秒以上 | 面番号変更モード |
| 連打 | 1秒以内に3回以上 | キャンセル |
| なし | 30秒間無操作 | タイムアウト |

## 備考
- ボタン検出はAXON側で実施
- SOMA側は状態監視のみ
- 変更確定はTGからの承認必要
- タイムアウト時は元の状態に戻す
- ドア開放中は変更操作禁止

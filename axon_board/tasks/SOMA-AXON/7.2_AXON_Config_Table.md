# 7.2 AXON 設定 Table 伝搬

## 概要
FRAMに保存されている設定テーブル（FACE番号・金額・Timeout）を読み出し、SETAXONコマンドで各AXONボードに書き込む。全ポートに対して順次実行。

## 使用コマンド

### SOMA → AXON
- **SETAXON (0x4A)**: AXON設定書き込み
  - SET_FACE_N: FACE番号
  - SET_CASH_VLU: 金額設定
  - SET_TOUT: タイムアウト値
  - SET_LED: LED設定
  - SET_SOL: ソレノイド設定

### AXON → SOMA
- **ACK (0x00)**: 設定受信確認

## タスク詳細

### 1. FRAMテーブル取得
- [ ] FRAM テーブル（FACE・金額・Timeout）を取得
- [ ] fram_load_entry(N, &entry) 呼び出し
- [ ] PORT-FLG確認（有効ポートのみ処理）
- [ ] 設定値の妥当性チェック
  - FACE番号: 0-255
  - 金額: 0-65535 (100円単位)
  - Timeout: 1-255秒

### 2. SETAXONコマンド構築 ✅
- [x] SETAXON で AXON に書き込み
- [x] 36バイトフレーム構築
  - Header: 0x14
  - Length: 0x20
  - Command: 0x4A (SETAXON)
  - Data[0]: FACE_N (entry.face_num)
  - Data[1]: SET_SOL (通常は0x00)
  - Data[2]: SET_LED (通常は0x00)
  - Data[3]: SET_TOUT (entry.timeout)
  - Data[4-5]: 予約
  - Data[6]: SET_FACE_N (entry.face_num)
  - Data[7-8]: SET_CASH_VLU (entry.cash_value)
  - Data[9-31]: 予約
  - CRC16: 計算値

### 3. UART送信とACK確認 ✅
- [x] ACK 確認
- [x] MUX-N番切替
- [x] SETAXON送信
- [x] ACK応答待機（タイムアウト: 100ms）
- [x] ACK検証
  - Header: 0x10
  - Length: 0x20
  - Command: 0x00 (ACK)
  - CRC16検証

### 4. 次ポートへ移行 ✅
- [x] MUX を進めて次ポートへ（N<10）
- [x] N < 9 の場合、N+1 へ
- [ ] エラー時のリトライ処理（最大3回）
- [ ] 全ポート完了で終了

### 5. エラーハンドリング
- [ ] FRAM読み出しエラー
- [ ] ACKタイムアウト
- [ ] CRCエラー
- [ ] 設定値範囲外エラー

## データフォーマット例

```
SETAXON for Port 1 (FACE #2, 100円, Timeout 5秒):
14 20 4A 02 00 00 05 00 00 02 01 00 00 00 00 00
00 00 00 00 00 00 00 00 00 00 00 00 23 01 00 00
00 00 [CRC16:2B]

Data部分の意味:
[0]: FACE_N = 0x02
[1]: SET_SOL = 0x00
[2]: SET_LED = 0x00
[3]: SET_TOUT = 0x05 (5秒)
[4-5]: 予約
[6]: SET_FACE_N = 0x02
[7-8]: SET_CASH_VLU = 0x0001 (100円)
[9-31]: 予約
```

- 設定変更時はFRAM更新後に実行

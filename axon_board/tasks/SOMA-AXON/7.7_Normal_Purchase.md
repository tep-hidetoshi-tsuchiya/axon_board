# 7.7 通常動作（購入）

## 概要
現金購入とキャッシュレス購入の2つのシーケンスを処理。現金購入はAXON自律動作、キャッシュレス購入はTG→SOMA→AXON連携で実施。両方とも回転検出後にFRAMカウンタを増加。

## 使用コマンド

### SOMA → AXON
- **CHKIRQ (0x49)**: 状態確認・回転検出
- **SETAXON (0x4A)**: ソレノイド制御（キャッシュレス時）

### AXON → SOMA
- **ATIRQ (0x6A)**: 状態応答
  - COIN_DET: 硬貨検出
  - ROT_DET: 回転検出
  - BLK_ON: ブロック状態

---

## A. 現金決済シーケンス

### 概要
顧客が硬貨を投入し、AXONボード側で金額判定・ソレノイド制御を自律実行。SOMA側は状態監視とカウンタ更新のみ実施。

### タスク詳細

#### 1. 硬貨投入検出 ✅
- [x] COIN_DET を CHKIRQ で取得
- [x] 定期CHKIRQ送信（50ms周期）
- [x] ATIRQ応答の status 解析
- [x] COIN_DETビット確認
  ```c
  bool coin_det = (status & COIN_DET_BIT) != 0;
  ```

#### 2. AXON自律動作監視 ✅
- [x] BLK_ON 解除→回転→売上確定
- [x] 状態遷移の監視
  ```
  1. COIN_DET=1 (硬貨投入)
  2. BLK_ON=1 (金額判定中)
  3. BLK_ON=0 (ブロック解除・ソレノイドON)
  4. ROT_DET=1 (回転検出)
  5. 売上成立
  ```

#### 3. 回転検出確認 ✅
- [x] ROT_DETビット監視
- [x] 回転完了の判定
- [ ] タイムアウト処理（例: 10秒）

#### 4. カウンタ増加
- [ ] **FRAM カウンタ増加**
- [ ] fram_increment_counter(port) 呼び出し
- [ ] 売上金額の記録（オプション）
- [ ] 売上時刻の記録（オプション）

#### 5. TG通知
- [ ] 売上完了STATUSをTGに送信
- [ ] 販売FACE番号
- [ ] 販売金額
- [ ] 累積販売数

### フロー図（現金決済）

```

    ↓
┌──────────────┐
│ CHKIRQ送信   │
│ (周期監視)   │

       ↓
  COIN_DET=1?
   ↓YES       NO→[ループ]
┌──────────────┐
│ 硬貨投入検出 │

       ↓
  BLK_ON=1?
   ↓YES
[金額判定中]
   ↓
  BLK_ON=0?
   ↓YES

   ↓
  ROT_DET=1?
   ↓YES
┌──────────────┐
│ 回転検出     │

       ↓
┌──────────────┐
```

## B. キャッシュレス決済シーケンス

### 概要
TGが決済処理を完了後、SOMAがSETAXONコマンドでAXONのソレノイドを制御。回転検出後にカウンタ更新とTG通知を実施。

### タスク詳細

#### 1. TG決済完了通知受信
- [ ] 決済完了後にソレノイド ON（SETAXON）
- [ ] TGから決済完了コマンド受信
- [ ] 決済金額の確認
- [ ] 対象FACE番号の確認
- [ ] 対象ポート番号の確認

#### 2. ソレノイドON指示 ✅
- [x] SETAXON構築（ソレノイドON）
  ```c
  SETAXON_PACKET setaxon;
  setaxon.command = 0x4A;
  setaxon.face_n = target_face;
  setaxon.set_sol = 0x01;  // ソレノイドON
  setaxon.set_led = 0x00;
  setaxon.set_tout = timeout_value;
  setaxon.set_face_n = target_face;
  setaxon.set_cash_vlu = cash_value;
  // CRC16計算
  ```
- [x] MUX切替
- [x] UART送信
- [x] ACK確認

#### 3. 回転検出 ✅
- [x] 回転検出（CHKIRQ）
- [x] 定期CHKIRQ送信（50ms周期）
- [x] ROT_DETビット監視
- [ ] タイムアウト設定（例: 10秒）

#### 4. ソレノイドOFF指示 ✅
- [x] ソレノイド OFF（SETAXON）
- [x] SETAXON構築（ソレノイドOFF）
  ```c
  setaxon.set_sol = 0x00;  // ソレノイドOFF
  ```
- [x] UART送信
- [x] ACK確認

#### 5. カウンタ増加とTG通知
- [ ] **FRAM カウンタ増加**
- [ ] fram_increment_counter(port) 呼び出し
- [ ] TGへ売上完了STATUS送信
- [ ] 決済IDの記録（オプション）

## エラーケース

| エラー | 検出条件 | 対処 |
|-------|---------|------|
| 回転タイムアウト | 10秒経過しても回転なし | ソレノイドOFF、TGへエラー通知 |
| ソレノイド異常 | ACKタイムアウト | 3回リトライ後エラー |
| 決済金額不一致 | FRAM金額 ≠ TG決済金額 | エラー通知、処理中止 |
| カウンタ更新失敗 | FRAM書込失敗 | エラーログ、TGへ通知 |

## 備考
- 現金決済: AXON完全自律動作
- キャッシュレス: SOMA制御・TG連携
- カウンタは両方式で必ず+1
- 回転タイムアウトは処理未了扱い（7.8参照）
- ソレノイドON時間: 最大5秒（設定可能）

# 7.5 面番号変更（0面利用）

## 概要
保守・メンテナンス時に特定ポートを無効化するため、FACE番号を0に設定。金額とカウンタは保持し、後で復帰可能にする。

## 使用コマンド

### SOMA → AXON
- **SETAXON (0x4A)**: FACE=0 書き込み
  - SET_FACE_N: 0 (無効化)
  - SET_CASH_VLU: 既存金額（保持）
  - SET_TOUT: 既存タイムアウト（保持）

### AXON → SOMA
- **ACK (0x00)**: 設定受信確認

## タスク詳細

### 1. 既存設定の読み出し
- [ ] fram_load_entry(port, &old_entry) 呼び出し
- [ ] 保持データの確認
  - cash_value: 既存金額設定（保持）

### 2. SETAXON 0面設定送信 ✅
- [x] FACE を 0 面に設定する SETAXON を送信
- [x] 36バイトフレーム構築
  - Header: 0x14
  - Length: 0x20
  - Command: 0x4A (SETAXON)
  - Data[0]: FACE_N (0x00)
  - Data[1]: SET_SOL (0x00)
  - Data[2]: SET_LED (0x00)
  - Data[3]: SET_TOUT (old_entry.timeout)
  - Data[6]: SET_FACE_N (0x00)
  - Data[7-8]: SET_CASH_VLU (old_entry.cash_value)
  - CRC16: 計算値
- [x] MUX切替
- [x] UART送信

### 3. ACK確認 ✅
- [x] ACK を確認
- [x] 応答待機（タイムアウト: 100ms）
- [x] ACK検証
  - Header: 0x10
  - Command: 0x00
  - CRC16検証
- [ ] エラー時のリトライ処理

### 4. FRAM更新（0面設定）
- [ ] **FRAM の FACE を 0 に書換え（金額・カウンタは保持）**
- [ ] 新エントリ作成
  ```c
  FRAM_AXON_Entry zero_entry;
  zero_entry.port_num = port;
  zero_entry.port_flg = 0;              // 無効化フラグ
  zero_entry.face_num = 0;              // 0面
  zero_entry.timeout = old_entry.timeout;      // 保持
  zero_entry.cash_value = old_entry.cash_value; // 保持
  zero_entry.counter = old_entry.counter;       // 保持
  memcpy(zero_entry.msn, old_entry.msn, 6);    // 保持
  zero_entry.fw_ver = old_entry.fw_ver;         // 保持
  ```
- [ ] fram_update_entry(port, &zero_entry) 呼び出し
- [ ] 更新結果確認

- [ ] ソレノイド動作禁止
- [ ] 購入処理無効化
- [ ] LED消灯またはエラー表示

## 保持データ例

```
0面設定前:
  Port 1: FACE #2, 100円, Counter=50

0面設定後:
  Port 1: FACE #0, 100円, Counter=50
           ^^^^^ 無効化  ^^^^^^^^^^^^ 保持
           
復帰時:
  Port 1: FACE #2, 100円, Counter=50
           ^^^^^ 復帰    ^^^^^^^^^^^^ 復元
```

## 0面の用途

### メンテナンスモード
- カプセル補充時の一時無効化
- 清掃・点検時の安全確保
- 金額変更作業中の無効化

### 故障対応
- AXON故障時の無効化
- 通信エラー時の無効化
- ソレノイド故障時の無効化

### 運用調整
- 一時的な販売停止
- 在庫切れ時の無効化
- イベント終了時の無効化

## 備考
- 0面 = PORT無効化状態
- データ保持により復帰時に実績継続
- 複数ポート同時無効化も可能
- 0面設定中も通信は可能（監視用）
- 緊急停止時にも使用可能
- 長期間の0面設定も問題なし
